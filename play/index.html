API 连接

填一个 OpenAI 兼容的接口。密钥只存在这台设备的浏览器里，请求从你的浏览器直接发给接口，不经过任何别的服务器。接口要允许浏览器跨域访问（CORS），大多数中转站和 DeepSeek、OpenRouter、Gemini 的兼容接口都可以。

配置方案

方案存在这台设备的浏览器里，切换方案会把下面几项和检定的裁判模型一起换掉。导出默认不带密钥，发给别人也不会漏 key；自己换电脑用就勾上。

模型

两项空着就照预设来。接口报 max_tokens 不对时把回复上限改小，比如 DeepSeek 填 8192；模型的上下文窗口比预设小的，上下文上限填模型的窗口大小。

预设「英式早餐」、角色卡和内嵌世界书都已经装好，不用另外导入。

存档

每一轮都会自动存进这台设备的浏览器，只要不清浏览器数据，下面这些存档一直都在。换设备或者怕丢，就导出带走：单局导出成 .jsonl，SillyTavern 也能读；「备份全部」把所有存档打成一个文件，换台电脑用「恢复备份」一次导回来。

跑团检定

你每发一句，先让裁判看这一步要不要掷骰：撬锁、潜入、搏斗、说服、让天问入侵这类成败难料的事才掷，闲聊、走路、亲热不掷。要掷就从道尔顿的技能或天问的技能线里挑一项，按熟练程度和难度算成功率，浏览器掷一个 d100，结果附在你这句话后面交给写作模型，正文照结果写。

裁判每轮只多一次很短的请求。想省钱省时间可以填一个便宜的小模型，同一个接口里的就行。

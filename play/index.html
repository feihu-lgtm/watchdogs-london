API 连接

填一个 OpenAI 兼容的接口。密钥只存在这台设备的浏览器里，请求从你的浏览器直接发给接口，不经过任何别的服务器。接口要允许浏览器跨域访问（CORS），大多数中转站和 DeepSeek、OpenRouter、Gemini 的兼容接口都可以。

模型

两项空着就照预设来。接口报 max_tokens 不对时把回复上限改小，比如 DeepSeek 填 8192；模型的上下文窗口比预设小的，上下文上限填模型的窗口大小。

预设「英式早餐」、角色卡和内嵌世界书都已经装好，不用另外导入。

存档

每一轮都会自动存进这台设备的浏览器。换设备时导出 .jsonl 带走，SillyTavern 的聊天记录也能导进来。
